  - question: "What size barrel bolt do I need for my gate?"
    answer: "For garden gates up to 1.2m wide, a 6-inch (150mm) barrel bolt provides adequate security. For larger gates 1.2-2m wide, use an 8-inch (200mm) bolt. For heavy double gates, use a 10-inch (250mm) bolt on each gate leaf. For shed doors, a 4-6 inch (100-150mm) bolt is sufficient. For cabinet and furniture, a 3-4 inch (75-100mm) bolt is appropriate. The bolt length should be proportional to the door size for both security and appearance."
  - question: "Can I use a barrel bolt as the primary lock?"
    answer: "Barrel bolts are designed as secondary locks or supplementary security, not as primary locks. They are surface-mounted and can be accessed from the inside only. For exterior doors, use a barrel bolt in combination with a primary keyed lock or deadbolt. The barrel bolt provides additional security when you are inside the property. The padlock loop version can be used as a primary lock on sheds and gates where the padlock provides the keyed access."
  - question: "How do I install a barrel bolt?"
    answer: "Mark the bolt position on the door edge and the strike plate position on the frame. The bolt should be mounted on the door and the strike plate on the frame. Pre-drill pilot holes for the screws to prevent wood splitting. Attach the bolt body to the door with the provided screws. Close the door and mark the strike plate position so the bolt pin aligns with the strike plate hole. Attach the strike plate to the frame. Test the bolt operation and adjust if necessary. The bolt should slide smoothly and engage fully into the strike plate."
  - question: "What is the padlock loop feature?"
    answer: "The padlock loop is a metal ring or hole integrated into the bolt handle that allows a padlock to be inserted. When the bolt is in the locked position and a padlock is attached through the loop, the bolt cannot be slid back to the open position without first removing the padlock. This converts the barrel bolt from a simple sliding lock to a keyed or combination-locked security device. This feature is particularly useful for gates, sheds, and external doors where the bolt needs to be securable from both sides."
